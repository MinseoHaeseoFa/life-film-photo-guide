# 인생이라는 필름 — 가장 빛나는 한 컷을 남기는 법

상황별로 바로 찾아 쓰는 사진 촬영 필드 가이드. **실전 카드 101장**에 **카드마다 다른 실사 필름 사진 101장 · 뷰파인더 HUD · Before/After 비교 · 3단계 · 현장 체크리스트**를 붙였습니다.

## 실행

```bash
cd life-film-photo-guide
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`index.html`을 직접 열어도 동작하지만, 로컬 서버로 여는 편이 확실합니다.

## 사진과 뷰파인더

- 사진은 35mm 필름 룩으로 생성한 **에디토리얼 이미지**입니다. 실제 촬영지나 인물의 기록 사진이 아니며, EXIF 표기는 카드가 가르치는 설정을 옮긴 예시입니다.
- **101장 카드가 101장의 서로 다른 사진을 하나씩** 씁니다(중복 사용 0건). 기존 33장은 주제에 맞는 카드에 한 번씩만 배치하고, 부족한 68장을 카드 주제에 맞춰 새로 생성했습니다.
- 카드 썸네일과 모달 뷰파인더에 **삼분할 격자 · 초점 사각 링 · 코너 브래킷 · EXIF·렌즈 배지**를 올렸습니다. 초점 좌표(`fx`,`fy`)와 썸네일 `object-position`은 각 사진에서 주 피사체가 실제로 있는 위치에 맞췄습니다.
- `Before`는 카드가 경고하는 실패를 실제 사진 위에서 재현합니다(수평 -4.2°, 디지털 줌 확대, 과노출·저노출, 손떨림, 채도 저하, 어색한 크롭 등). `After`는 교정된 구도에 초점 링·수평선·교차점 점을 맞춰 보여 줍니다.
- 썸네일은 `loading="lazy"` + `decoding="async"`로 초기 로딩을 가볍게 유지합니다(사진 폴더 전체 8.7MB).

### 2) 전수 중복 정리

- 카드 1쌍 통합: `scene-first`(배경을 먼저 정하고 내가 들어간다) + `selfie-marker`(물병으로 내 자리 먼저 확인) → **`selfie-marker` 1장**. 두 카드의 3단계(빈 프레임 → 고정 → 그 자리에 들어가 타이머)가 사실상 같고, 물병 마커 카드가 더 구체적인 실행법을 담고 있어 한 장으로 합쳤습니다(분류는 혼자 여행·풍경 두 곳).
- 3단계 중복 수정: `body-turn`(몸은 45도, 얼굴만 정면)의 2·3단계가 `weight-shift`·`chin-forward` 카드의 핵심과 그대로 겹쳐, 이 카드만의 축(어깨선·얼굴 방향)으로 바꿨습니다.
- 고치지 않고 유지한 유사 쌍과 이유: `light-trail`↔`crowd-erase`(장노출·고정은 같지만 대상이 차량 궤적 vs 행인), `backview`↔`space`(뒷모습 vs 시선 여백), `minimal-space`↔`mountain-scale`(여백 미니멀 vs 규모), `exposure-slider`↔`backlight-rim`(역광에서 하늘 살리기 vs 얼굴 살리기), `night-market`↔`market-food`(골목 풍경 vs 먹거리 디테일). 기계 유사도 최대 0.188로 임계 0.30을 넘는 쌍은 없습니다.
- 출처 레지스트리 중복 주소 4건 정리: `sd_night`→`sd`, `jamie_pose`→`jamie`, `canon_comp`→`canon`, `ontour_night`→`tour`(같은 주소를 두 이름으로 가지고 있었음). 참고 링크 수치는 카드가 실제로 인용한 **고유 주소** 기준으로 계산합니다.
