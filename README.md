# 인생이라는 필름 — 가장 빛나는 한 컷을 남기는 법

상황별로 바로 찾아 쓰는 사진 촬영 필드 가이드. 39개의 실전 카드에 **SVG 뷰파인더 다이어그램 · Before/After 비교 · 3단계 · 현장 체크리스트**를 붙였습니다.

## 실행

```bash
cd life-film-photo-guide
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

파일을 더블클릭해 `index.html`을 열어도 동작하지만, 로컬 서버로 여는 편이 확실합니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 페이지 구조 (히어로 · 필터 · 카드 그리드 · 출처 검증 · 모달) |
| `styles.css` | 필름/페이퍼 톤 디자인, PC 3열 / 모바일 1열 반응형 |
| `data.js` | 카드 39개 데이터(상황·난이도·렌즈·원리·3단계·실패·체크·출처)와 출처 레지스트리 |
| `diagrams.js` | 카드별 커스텀 SVG 뷰파인더 39종 (외부 이미지 0장) |
| `app.js` | 필터·검색·스크랩·모달·체크리스트 저장(localStorage) |

| `qa/` | 로컬 브라우저 검증 스크립트와 전체 다이어그램 시트 |

## 카드 구성 (39장)

- **폰 카메라 세팅 5** — 격자/수평, 렌즈 버튼, 노출 슬라이더, 3초 타이머, 프로 모드 색감
- **혼자 여행·셀카봉 7** — 셀카봉 높이, 난간 고정, 자리 표시, 뒤태, 걷기, 초광각 셀카, 인물/배경 비율
- **인물·포즈 9** — 눈 위치, 손, 몸 45도, 기대기, 프레임 속 프레임, 여백, 로우앵글, 크롭, 인물 모드
- **풍경·여행지 6** — 수평선 비율, 리딩 라인, 대칭·반영, 색 대비, 시선 높이, 역광
- **카페·음식 4** — 창가 옆빛, 탑뷰, 눈높이 단면, 접사
- **야경·역광·감성 8** — 물웅덩이 반영, 빗줄기 셔터, 도시 야경, 불꽃놀이, 라이트 트레일, 은하수, 별, 노을

## 인터랙션

- 상황 칩 · 실시간 검색 · 난이도 · 렌즈 배율 · 스크랩 모아보기
- 카드 → 모달: `Before`(아쉬운 예) ↔ `After`(인생샷), `삼분할선 ON/OFF`
- 현장 체크리스트: `localStorage`에 카드별 저장, 진행률 표시
- 이전/다음 카드 이동, 관련 카드 3장 바로가기, 랜덤 한 컷
- ESC 닫기, ←/→ 이동

## 출처와 한계

- 요청받은 링크 13개는 브라우저로 직접 열어 캡션/본문을 확인했습니다. 확인 10 · 부분 확인 2 · 접근 제한 1(`@pure.moood` Threads)이며, 접근 제한 링크의 내용은 **넣지 않았습니다**.
- 카드의 참고 링크는 모두 실제 접속(HTTP 200)을 확인한 주소입니다. Adobe 문서 2건은 서버가 403을 반환해 제외했습니다.
- 인스타그램·유튜브 영상의 **화면 전체를 본 것은 아니고**, 캡션·자막·확인 가능한 프레임 범위에서 확인한 내용만 반영했습니다.
- 기종·OS 버전에 따라 메뉴 이름이 다를 수 있습니다(갤럭시: 촬영 가이드 / 아이폰: 격자·수준기 등).
