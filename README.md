# 인생이라는 필름 — 가장 빛나는 한 컷을 남기는 법

상황별로 바로 찾아 쓰는 사진 촬영 필드 가이드. **실전 카드 100장**에 **실사 필름 사진 · 카메라 뷰파인더 HUD · Before/After 비교 · 3단계 · 현장 체크리스트**를 붙였습니다.

## 실행

```bash
cd life-film-photo-guide
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

`index.html`을 직접 열어도 동작하지만, 로컬 서버로 여는 편이 확실합니다.

## 사진과 뷰파인더

- 사진은 35mm 필름 룩으로 생성한 **에디토리얼 이미지**입니다. 실제 촬영지나 인물의 기록 사진이 아니며, EXIF 표기는 카드가 가르치는 설정을 옮긴 예시입니다.
- 카드 썸네일과 모달 뷰파인더에 **삼분할 격자(0.75px) · 초점 사각 링 · 코너 브래킷 · 상단/하단 EXIF·렌즈 배지**를 올렸습니다.
- `Before`는 카드가 경고하는 실패를 실제 사진 위에서 재현합니다(수평 -4.2°, 디지털 줌 확대, 과노출·저노출, 손떨림, 채도 저하, 어색한 크롭 등). `After`는 교정된 구도에 초점 링·수평선·교차점 점을 맞춰 보여 줍니다.

## 인터랙션

- 상황 칩 · 실시간 검색 · 난이도 · 렌즈 배율 · 스크랩 모아보기
- 카드 → 모달: `Before` ↔ `After`, `삼분할선 ON/OFF`
- 현장 체크리스트는 뷰파인더 바로 아래에 배치, `localStorage`에 카드별 저장
- 이전/다음 카드 이동, 랜덤 한 컷, ESC 닫기, ←/→ 이동
